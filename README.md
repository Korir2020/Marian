# School AI Platform

An AI-powered school management, learning analytics, and personalized education platform.

## Vision

Build a modern education platform that helps schools manage academic operations while using AI to improve learning, teaching, communication, and decision-making.

## Core Features

- Student management
- Teacher management
- Classes and subjects
- Exams and marks
- Grading and reports
- School analytics
- AI-powered learning
- Personalized learning
- Early-warning analytics
- Offline-first support
- Parent communication
- Fees and mobile-money integration

## Initial Target

Kenya, with an architecture that can later support other countries.

## Development Status

🚧 Early development — architecture and foundation stage.
